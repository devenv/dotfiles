# Privacy Policy for Sigma Tabs

**Last Updated:** January 2025

## Overview

Sigma Tabs is a Chrome extension that helps you manage browser tabs with hierarchical organization, locking, and auto-unload features.

## Data Collection

**Sigma Tabs does not collect, transmit, or share any user data.**

All data is stored locally on your device using Chrome's built-in storage API (`chrome.storage.local`).

## What Data Is Stored Locally

The extension stores the following information **only on your local device**:

- Tab metadata (titles, URLs, favicons)
- Tab hierarchy relationships (parent-child)
- User preferences (auto-unload threshold, collapsed/expanded state)
- Lock and pin states for tabs

## Data Sharing

- No data is sent to external servers
- No analytics or tracking
- No third-party services
- No network requests (except loading favicons from websites you visit)

## Permissions

The extension requires the following Chrome permissions:

| Permission | Purpose |
|------------|---------|
| `tabs` | Read tab information (title, URL, favicon) for display |
| `storage` | Store your tab hierarchy and preferences locally |
| `sidePanel` | Display the sidebar interface |
| `contextMenus` | Provide right-click menu options |
| `alarms` | Schedule auto-unload timer checks |
