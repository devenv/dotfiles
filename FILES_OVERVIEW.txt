CORE FINDINGS (TL;DR)
────────────────────────────────────────────────────────────────────────────────

Finding 1: Different Tools, Different Problems
  Claude Code = autonomous agent for hands-off operations
  Cursor = interactive IDE for hands-on development
  Verdict = Both needed; not competitors

Finding 2: Claude Code Unique Advantages
  • Skill system (auto-routes to 28 workflows)
  • Hooks (enforces multi-tenant safety)
  • Unlimited MCPs (for 30+ services)
  • Headless mode (overnight batch jobs)

Finding 3: Cursor Limitations for Nilus
  • No skill system (manual workflow choice)
  • 40-tool limit (can't integrate 30+ services)
  • No hooks (can't enforce multi-tenant safety)
  • Not designed for headless automation

Finding 4: Financial Case is Strong
  Setup cost: $40-50K (one-time)
  Annual savings: $40-66K (from automation)
  Payback: 1 year; 3-year ROI: $100-160K+

Finding 5: Recommendation for Nilus
  Primary: Claude Code (with full skill system + hooks)
  Secondary: Cursor (for interactive development)
  Timeline: 3-4 weeks to production
